╔════════════════════════════════════════════════════════════════════════════╗
║                          FLUXO DE DADOS                                     ║
╚════════════════════════════════════════════════════════════════════════════╝

 1. Usuário seleciona arquivo ─────▶ Input file
 2. Validação client-side ──────────▶ JavaScript
 3. Preview da imagem ──────────────▶ FileReader API
 4. Usuário salva formulário ───────▶ Submit
 5. Criar registro (Professional/Service) ─▶ POST /api/establishment/.../
 6. Upload do arquivo ──────────────▶ POST /api/files/.../upload
 7. Validação e sanitização ────────▶ FileStorageService
 8. Salvar arquivo no disco ────────▶ /uploads/...
 9. Atualizar imageUrl ─────────────▶ Database
10. Retornar sucesso ──────────────▶ Frontend
11. Recarregar lista ──────────────▶ Display com nova imagem

╔════════════════════════════════════════════════════════════════════════════╗
║                          CAMADAS DE SEGURANÇA                               ║
╚════════════════════════════════════════════════════════════════════════════╝

 Layer 1: Frontend
  ├─ Validação de extensão (accept attribute)
  ├─ Validação de tamanho (5MB)
  └─ Validação de tipo MIME

 Layer 2: Backend (FileStorageService)
  ├─ Validação de arquivo vazio
  ├─ Whitelist de extensões (jpg, jpeg, png)
  ├─ Validação de tamanho (5MB)
  ├─ Sanitização de folder name
  ├─ Proteção contra path traversal
  ├─ Validação de limites de diretório
  └─ Geração de UUID único

 Layer 3: Application Layer
  ├─ Validação de establishmentId
  ├─ Verificação de ownership
  └─ Isolamento de dados

 Layer 4: Infrastructure
  ├─ Spring Security
  ├─ Limite de tamanho no Tomcat
  └─ Permissões de sistema de arquivos
