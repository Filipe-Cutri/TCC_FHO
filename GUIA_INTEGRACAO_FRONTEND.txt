GUIA DE INTEGRAÇÃO FRONTEND - NOVOS ENDPOINTS
==============================================

Este guia explica como integrar o frontend com os novos endpoints do backend.

BASE URL
========
Local: http://localhost:8080
Produção: [URL_PRODUCAO]

AUTENTICAÇÃO
============
Todos os endpoints requerem que o usuário esteja autenticado.
Use os tokens/sessões já implementados no sistema.

1. NOTIFICAÇÕES DO CLIENTE
===========================

A. Buscar notificações não lidas (para badge de notificações)
--------------------------------------------------------------
GET /api/notifications/client/{clientId}/unread/count

Exemplo JavaScript:
```javascript
async function getUnreadCount(clientId) {
    const response = await apiClient.get(`/api/notifications/client/${clientId}/unread/count`);
    return response.count; // retorna número de notificações não lidas
}
```

Uso: Exibir badge com contador na barra de navegação


B. Buscar todas notificações não lidas
--------------------------------------
GET /api/notifications/client/{clientId}/unread

Exemplo JavaScript:
```javascript
async function getUnreadNotifications(clientId) {
    const response = await apiClient.get(`/api/notifications/client/${clientId}/unread`);
    return response.data; // array de notificações
}
```

Uso: Lista de notificações no dropdown ou página de notificações


C. Marcar notificação como lida
--------------------------------
PUT /api/notifications/{id}/read

Exemplo JavaScript:
```javascript
async function markAsRead(notificationId) {
    const response = await apiClient.put(`/api/notifications/${notificationId}/read`);
    return response.success;
}
```

Uso: Quando usuário clica na notificação


D. Marcar todas como lidas
---------------------------
PUT /api/notifications/client/{clientId}/read-all

Exemplo JavaScript:
```javascript
async function markAllAsRead(clientId) {
    const response = await apiClient.put(`/api/notifications/client/${clientId}/read-all`);
    return response.success;
}
```

Uso: Botão "Marcar todas como lidas"


2. HISTÓRICO DE SERVIÇOS DO CLIENTE
====================================

A. Buscar histórico completo
----------------------------
GET /api/client/service-history/{clientId}

Exemplo JavaScript:
```javascript
async function getServiceHistory(clientId) {
    const response = await apiClient.get(`/api/client/service-history/${clientId}`);
    return response.data; // array de agendamentos passados
}
```

Retorna:
- Todos agendamentos passados do cliente
- Ordenados por data (mais recente primeiro)
- Inclui: serviço, profissional, data, valor

Uso: Página de histórico de serviços


B. Buscar perfil completo com estatísticas
------------------------------------------
GET /api/client/profile/{clientId}

Exemplo JavaScript:
```javascript
async function getClientProfile(clientId) {
    const response = await apiClient.get(`/api/client/profile/${clientId}`);
    return {
        profile: response.data.profile,
        history: response.data.serviceHistory,
        upcoming: response.data.upcomingAppointments,
        total: response.data.totalServices
    };
}
```

Retorna:
- Perfil do cliente (sem senha)
- Histórico de serviços
- Agendamentos futuros
- Total de serviços realizados

Uso: Página de perfil do cliente

4. CONFIRMAÇÃO DE AGENDAMENTO
==============================

PUT /api/appointment/{id}/confirm

Exemplo JavaScript:
```javascript
async function confirmAppointment(appointmentId) {
    const response = await apiClient.put(`/api/appointment/${appointmentId}/confirm`);
    if (response.success) {
        alert('Agendamento confirmado com sucesso!');
        // Notificação automática será enviada pelo backend
    }
    return response;
}
```

Uso: Botão "Confirmar agendamento" na tela de detalhes


5. PAGAMENTOS
=============

A. Buscar pagamentos do cliente
--------------------------------
GET /api/payments/client/{clientId}

Exemplo JavaScript:
```javascript
async function getClientPayments(clientId) {
    const response = await apiClient.get(`/api/payments/client/${clientId}`);
    return response.data; // array de pagamentos
}
```

Uso: Página de histórico de pagamentos


B. Criar pagamento
------------------
POST /api/payments

Exemplo JavaScript:
```javascript
async function createPayment(paymentData) {
    const response = await apiClient.post('/api/payments', {
        clientId: paymentData.clientId,
        establishmentId: paymentData.establishmentId,
        appointmentId: paymentData.appointmentId, // opcional
        amount: paymentData.amount,
        paymentMethod: paymentData.method, // PIX, CREDIT_CARD, etc
        clientName: paymentData.clientName,
        serviceName: paymentData.serviceName
    });
    return response;
}
```

Uso: Tela de pagamento após agendamento


C. Completar pagamento
----------------------
PUT /api/payments/{id}/complete

Exemplo JavaScript:
```javascript
async function completePayment(paymentId, transactionId) {
    const response = await apiClient.put(`/api/payments/${paymentId}/complete`, {
        transactionId: transactionId
    });
    return response;
}
```

Uso: Após confirmação de pagamento (PIX, cartão, etc)


EXEMPLO COMPLETO - PÁGINA DE NOTIFICAÇÕES
==========================================

```javascript
// notifications-page.js
class NotificationsPage {
    constructor() {
        this.clientId = this.getClientIdFromSession();
        this.init();
    }
    
    async init() {
        await this.loadNotifications();
        this.setupEventListeners();
        this.startPolling();
    }
    
    async loadNotifications() {
        try {
            // Buscar notificações não lidas
            const unreadResponse = await apiClient.get(
                `/api/notifications/client/${this.clientId}/unread`
            );
            
            // Atualizar UI
            this.displayNotifications(unreadResponse.data);
            this.updateBadge(unreadResponse.unreadCount);
            
        } catch (error) {
            console.error('Erro ao carregar notificações:', error);
        }
    }
    
    displayNotifications(notifications) {
        const container = document.getElementById('notifications-list');
        container.innerHTML = '';
        
        notifications.forEach(notification => {
            const element = this.createNotificationElement(notification);
            container.appendChild(element);
        });
    }
    
    createNotificationElement(notification) {
        const div = document.createElement('div');
        div.className = 'notification-item';
        div.innerHTML = `
            <h4>${notification.title}</h4>
            <p>${notification.message}</p>
            <small>${this.formatDate(notification.createdAt)}</small>
        `;
        
        // Click para marcar como lida
        div.addEventListener('click', async () => {
            await this.markAsRead(notification.id);
            div.classList.add('read');
        });
        
        return div;
    }
    
    async markAsRead(notificationId) {
        try {
            await apiClient.put(`/api/notifications/${notificationId}/read`);
            await this.loadNotifications(); // Recarregar
        } catch (error) {
            console.error('Erro ao marcar como lida:', error);
        }
    }
    
    async markAllAsRead() {
        try {
            await apiClient.put(`/api/notifications/client/${this.clientId}/read-all`);
            await this.loadNotifications();
        } catch (error) {
            console.error('Erro ao marcar todas como lidas:', error);
        }
    }
    
    updateBadge(count) {
        const badge = document.getElementById('notification-badge');
        badge.textContent = count;
        badge.style.display = count > 0 ? 'block' : 'none';
    }
    
    setupEventListeners() {
        const markAllBtn = document.getElementById('mark-all-read-btn');
        if (markAllBtn) {
            markAllBtn.addEventListener('click', () => this.markAllAsRead());
        }
    }
    
    startPolling() {
        // Verificar novas notificações a cada 30 segundos
        setInterval(() => this.loadNotifications(), 30000);
    }
    
    getClientIdFromSession() {
        const session = window.clientSession?.getSession();
        return session?.id;
    }
    
    formatDate(dateString) {
        const date = new Date(dateString);
        return date.toLocaleString('pt-BR');
    }
}

// Inicializar quando a página carregar
document.addEventListener('DOMContentLoaded', () => {
    new NotificationsPage();
});
```

EXEMPLO COMPLETO - PÁGINA DE HISTÓRICO
=======================================

```javascript
// service-history-page.js
class ServiceHistoryPage {
    constructor() {
        this.clientId = this.getClientIdFromSession();
        this.init();
    }
    
    async init() {
        await this.loadHistory();
        await this.loadStatistics();
    }
    
    async loadHistory() {
        try {
            const response = await apiClient.get(
                `/api/client/service-history/${this.clientId}`
            );
            
            this.displayHistory(response.data);
            
        } catch (error) {
            console.error('Erro ao carregar histórico:', error);
        }
    }
    
    async loadStatistics() {
        try {
            const response = await apiClient.get(
                `/api/client/profile/${this.clientId}`
            );
            
            this.displayStatistics({
                total: response.data.totalServices,
                upcoming: response.data.upcomingAppointments.length
            });
            
        } catch (error) {
            console.error('Erro ao carregar estatísticas:', error);
        }
    }
    
    displayHistory(appointments) {
        const container = document.getElementById('history-list');
        container.innerHTML = '';
        
        if (appointments.length === 0) {
            container.innerHTML = '<p>Nenhum serviço realizado ainda.</p>';
            return;
        }
        
        appointments.forEach(appointment => {
            const card = this.createHistoryCard(appointment);
            container.appendChild(card);
        });
    }
    
    createHistoryCard(appointment) {
        const div = document.createElement('div');
        div.className = 'history-card';
        div.innerHTML = `
            <div class="service-info">
                <h4>${appointment.serviceName}</h4>
                <p>Profissional: ${appointment.professionalName}</p>
                <p>Data: ${this.formatDate(appointment.appointmentDateTime)}</p>
                <p>Valor: R$ ${this.formatPrice(appointment.servicePrice)}</p>
            </div>
            <div class="status-badge ${appointment.status.toLowerCase()}">
                ${this.getStatusLabel(appointment.status)}
            </div>
        `;
        return div;
    }
    
    displayStatistics(stats) {
        document.getElementById('total-services').textContent = stats.total;
        document.getElementById('upcoming-count').textContent = stats.upcoming;
    }
    
    getStatusLabel(status) {
        const labels = {
            'COMPLETED': 'Concluído',
            'CANCELLED': 'Cancelado',
            'SCHEDULED': 'Agendado',
            'CONFIRMED': 'Confirmado'
        };
        return labels[status] || status;
    }
    
    formatDate(dateString) {
        const date = new Date(dateString);
        return date.toLocaleDateString('pt-BR');
    }
    
    formatPrice(price) {
        return parseFloat(price).toFixed(2).replace('.', ',');
    }
    
    getClientIdFromSession() {
        const session = window.clientSession?.getSession();
        return session?.id;
    }
}

// Inicializar
document.addEventListener('DOMContentLoaded', () => {
    new ServiceHistoryPage();
});
```

NOTAS IMPORTANTES
=================

1. TRATAMENTO DE ERROS
   - Sempre use try-catch
   - Mostre mensagens amigáveis ao usuário
   - Log erros no console para debug

2. LOADING STATES
   - Mostre indicadores de carregamento
   - Desabilite botões durante requisições
   - Use skeleton screens quando possível

3. POLLING
   - Notificações: 30 segundos
   - Agendamentos: 60 segundos
   - Use WebSockets se disponível (futuro)

4. CACHE
   - Cache perfil do cliente
   - Invalide após mudanças
   - Use localStorage com cuidado

5. OTIMIZAÇÃO
   - Carregue apenas dados necessários
   - Use paginação quando disponível
   - Minimize requisições duplicadas

6. SEGURANÇA
   - Nunca exponha tokens em URLs
   - Valide dados antes de enviar
   - Sanitize inputs do usuário
