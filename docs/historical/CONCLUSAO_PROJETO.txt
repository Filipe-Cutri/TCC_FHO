EXECUTANDO O PROJETO
====================

Backend:
1. Navegar para pasta: cd back-end
2. Build: ./gradlew build
3. Run: ./gradlew bootRun
4. Testes: ./gradlew test

Frontend:
1. Servir arquivos estáticos ou usar servidor HTTP
2. Acessar páginas em /front-end/src/pages/

Banco de Dados:
1. Aplicar schema: database_schema.sql
2. Aplicar migração: database_migration_add_establishment_to_client.sql
